End-to-end customer churn analysis for a telecommunications company. Python, SQL, Power BI dashboard. Identifies key churn drivers (contract type, tenure, payment method) and provides business recommendations.

Analysis of financial operations and organizational performance across departments and regions (8,900 records, 39 variables). ROI, EBITDA, gross margin, operational efficiency.

Data cleaning, SQL analysis and interactive dashboard on the OSMI Mental Health in Tech Survey. Key finding: family history is the strongest predictor of treatment-seeking behavior.

Case study based on my bachelor's thesis — quantitative psychology research using Pearson correlation, regression, ANOVA and Tukey post-hoc tests in jamovi.
